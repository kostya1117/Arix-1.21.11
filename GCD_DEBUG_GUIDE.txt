                    GCD DEBUG GUIDE
═══════════════════════════════════════════════════════════════

Как проверить что GCD работает нормально:

1. БЫСТРАЯ ПРОВЕРКА (в коде):
   ─────────────────────────────
   SensitivityUtil.debugGCD();
   
   Выведет:
   - Текущую чувствительность мыши
   - Значение GCD (raw)
   - Значение GCD (×0.15)
   - Валидна ли ротация

2. ПОЛНАЯ ПРОВЕРКА СИСТЕМЫ:
   ──────────────────────────
   SensitivityUtil.fullGCDCheck();
   
   Выведет:
   - Все параметры GCD
   - Текущую ротацию игрока
   - Тест нормализации ротации

3. ПРОВЕРКА НОРМАЛИЗАЦИИ:
   ──────────────────────
   Rotation target = new Rotation(yaw, pitch);
   SensitivityUtil.debugRotationNormalization(target);
   
   Выведет:
   - Оригинальную ротацию
   - Нормализованную ротацию
   - Текущую ротацию игрока

4. ПРОВЕРКА ДЕЛЬТЫ:
   ────────────────
   Rotation from = new Rotation(0, 0);
   Rotation to = new Rotation(45, 30);
   SensitivityUtil.debugRotationDelta(from, to);
   
   Выведет:
   - Дельту между ротациями
   - Как она округляется до GCD
   - Угол между ротациями

5. ПОЛНЫЙ ТЕСТ (рекомендуется):
   ────────────────────────────
   GCDTest.runFullTest();
   
   Выведет:
   - Базовый GCD тест
   - Тест дельты
   - Тест интерполяции
   - Тест нормализации

6. ТЕСТ ДИАПАЗОНА ЧУВСТВИТЕЛЬНОСТИ:
   ─────────────────────────────────
   GCDTest.testSensitivityRange();
   
   Выведет GCD для разных значений чувствительности

═══════════════════════════════════════════════════════════════

ЧТО ПРОВЕРЯТЬ:

✓ GCD Value должен быть > 0
✓ GCD Value не должен быть NaN или Infinity
✓ Нормализованная ротация должна быть валидна
✓ Pitch должен быть в диапазоне [-90, 90]
✓ Дельта должна быть округлена до GCD

═══════════════════════════════════════════════════════════════

ВОЗМОЖНЫЕ ПРОБЛЕМЫ:

❌ GCD = 0 или отрицательный
   → Проверь формулу в getGCD()
   
❌ GCD = NaN или Infinity
   → Проверь деление на 0 в getGCDValue()
   
❌ Pitch > 90 или < -90
   → Проверь Mth.clamp() в normalize()
   
❌ Нормализованная ротация не совпадает с ожидаемой
   → Проверь rotationDeltaTo() и angleDifference()

═══════════════════════════════════════════════════════════════

ПРИМЕР ИСПОЛЬЗОВАНИЯ В КОДЕ:

// В AttackHandler или другом месте:
public void testGCD() {
    // Быстрая проверка
    SensitivityUtil.debugGCD();
    
    // Или полная проверка
    GCDTest.runFullTest();
}
